# Telorax API Docs

Interactive docs and API playground built with **React + styled-components** (JavaScript).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173/docs/](http://localhost:5173/docs/) with `telorax serve` running on port 8000.

## Production build

```bash
npm run build
```

Output goes to `dist/`. Telorax serves it at `/docs/` when the folder exists.
